# Portfolio · Gastón M. Mansilla

Sitio estático de una sola página (HTML + CSS + un poco de JavaScript). No necesita instalar nada ni compilar: se publica tal cual en GitHub Pages.

Los colores, tipografías y espaciados salen del sistema de diseño **Nubix** del archivo de Figma y están como variables CSS al principio de `css/styles.css`.

## Estructura

```
index.html            Contenido de la página
casos/nubix.html      Página del caso Nubix (plantilla para los otros casos)
casos/referidos.html  Página del caso Referidos
casos/usuarios.html   Página del caso Usuarios y permisos
casos/nubix-hoy/      Réplica anonimizada del producto actual que el caso Nubix incrusta en iframes: `hoy.html` + `hoy.css` (cards, “elegido”, listas y modales; un fragmento por hash, p. ej. `#hosting`) y `sidebar.html` + `sidebar.css` (el sidebar: `#expandido`, `#colapsado`, `#mobile-abierto`, `#estados` con hover y foco forzados, `#referencia` e `#invitado`; con el mini-JS de la réplica: flecha, ítem padre, clic afuera, tema). El CSS es el compilado del producto recortado a lo que se usa. Lleva `noindex`
css/styles.css        Estilos y tokens (variables al inicio del archivo)
css/case-usuarios.css  Estilos del caso Usuarios y permisos (prefijo `usr-`)
css/case-visuals.css  Visuales de los casos hechos en código (Nubix: tarjetas de cifras, Hallazgo 1 — benchmark, botones, paleta, radios, badges —, Hallazgo 2 — tablas —, Hallazgo 3 — headers —, Hallazgo 4 — sidebar, prefijo `nxsb-` — y Hallazgo 5 — cards, “elegido”, listas y modales; ojo: `nxb-` ya es el botón del catálogo)
js/main.js            Menú móvil, sección activa, botón "Copiar correo" y aviso (toast)
js/analytics.js       Estadísticas de visitas con GoatCounter (código gmansilla24; ver "Estadísticas de visitas")
js/case-nav.js        Índice fijo de la página del caso (Nubix): resalta la sección que se está leyendo
js/case-specimens.js  Muestras interactivas del caso (Nubix): configurador de botones, tablas que ordenan y se seleccionan, ajuste de los marcos de celular, de las pantallas del prototipo y de los iframes con alto automático
fonts/                Nunito (autoalojada, licencia OFL) y un subconjunto de Material Icons (licencia Apache 2.0) para la réplica de las tablas de producción (`nx-old-icons`) y de las cards, listas y sidebar (`nx-hoy-*` y `nx-sb-*`, solo los íconos que se usan; la fuente de íconos usa la feature `rlig`, así que al hacer otro subconjunto hay que conservarla)
assets/icons/         Íconos SVG exportados de Figma
assets/img/           Foto del hero y capturas de los casos
assets/docs/          CV y handoffs de los prototipos y del sistema de diseño (Usuarios y permisos, Programa de referidos, Sistema de diseño), en PDF (ver "Antes de publicar")
favicon.svg
```

## Verlo en tu computadora

Desde esta carpeta, en la terminal:

```
python3 -m http.server 8000
```

y abrí http://localhost:8000. También sirve la extensión Live Server de VS Code. (Abrir `index.html` con doble clic funciona casi todo, pero el botón de copiar necesita `localhost` o `https`.)

## Antes de publicar

1. **Imágenes**: ya están las reales en `assets/img/` (WebP). La foto es de 800 × 800 px, las miniaturas de las tarjetas de 736 × 600 y las portadas de los casos de 932 × 712: todas al doble de lo que se muestra, para que se vean nítidas en pantallas retina.
2. **CV público** (actualizado, ya lista `https://gmansilla24.github.io` como portfolio): `assets/docs/CV-Gaston-Mansilla.pdf` es la versión sin referencias; incluye la fecha de nacimiento por decisión de Gastón. Ojo: el PDF de un repositorio público lo puede descargar cualquiera, así que cualquier dato personal que tenga queda visible.
3. **Handoffs de los prototipos** (`assets/docs/Handoff-Usuarios-y-permisos.pdf`, `assets/docs/Handoff-Programa-de-referidos.pdf` y `assets/docs/Handoff-Sistema-de-diseno.pdf`, botón "Handoff" en el hero de `casos/usuarios.html`, `casos/referidos.html` y `casos/nubix.html`, se abren en una pestaña nueva como el CV): son los PDF exportados de los documentos de handoff. Si un documento cambia, volver a exportarlo (A4, sin fecha ni firma) y reemplazar el archivo con el mismo nombre. Si se agrega un prototipo con handoff en otro caso, repetir el mismo botón.
4. **Estadísticas de visitas**: ya está conectado el código `gmansilla24` de GoatCounter en `js/analytics.js`. Después de publicar, entrar una vez al sitio publicado y confirmar que la visita aparece en `https://gmansilla24.goatcounter.com` (detalle en "Estadísticas de visitas").
5. **Indexación**: se quitó el `noindex` de `index.html` y de los tres archivos de `casos/`, así que Google puede indexar el sitio. Los prototipos (`prototipos/`) y las réplicas (`casos/nubix-hoy/`) conservan su propio `noindex` a propósito: son demos con datos de ejemplo y no deberían aparecer en buscadores.
6. Revisar el enlace de "Leer completas en LinkedIn" (`index.html`, busca `details/recommendations`) y confirmar con las tres personas que están de acuerdo con que se publiquen sus recomendaciones.

## Publicar en GitHub Pages

1. Crear un repositorio **público** en GitHub. Si se llama `gmansilla24.github.io`, el sitio queda en `https://gmansilla24.github.io`. Con cualquier otro nombre queda en `https://gmansilla24.github.io/nombre-del-repo`. Todas las rutas son relativas, así que funcionan en ambos casos.
2. Subir el contenido de esta carpeta:
   ```
   git init
   git add .
   git commit -m "Portfolio"
   git branch -M main
   git remote add origin https://github.com/gmansilla24/NOMBRE-DEL-REPO.git
   git push -u origin main
   ```
3. En el repositorio: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `(root)` → Save**. A los pocos minutos aparece la URL.

## Estadísticas de visitas

Usa [GoatCounter](https://www.goatcounter.com), gratis y de código abierto. Según su documentación identifica las visitas únicas sin cookies, con un hash que no identifica a la persona, y por eso no necesita un banner de consentimiento (es lo que dice la herramienta; no es asesoramiento legal).

1. La cuenta ya está creada: el código del sitio es `gmansilla24` y el panel está en `https://gmansilla24.goatcounter.com`.
2. El código está cargado en `js/analytics.js` (`var CODE = "gmansilla24";`). Ese archivo ya está enlazado en las 21 páginas (inicio, los tres casos y todas las páginas de los prototipos), cada una con su ruta relativa. Si algún día cambia el código, es el único lugar a editar. Las pantallas del prototipo que el caso Nubix muestra en un iframe se cargan con `?embed`: así no cuentan como visita y no muestran el panel "Probar estados".
3. Las visitas empiezan a aparecer cuando el sitio esté publicado. Para comprobarlo, abrir el sitio publicado una vez (no desde tu computadora) y mirar el panel.

Qué cuenta: las visitas por página (se ve cuáles casos y prototipos se abren), de dónde llegaron (por ejemplo desde LinkedIn), país, navegador y tamaño de pantalla. Qué no cuenta: las visitas desde tu computadora (localhost o un archivo local), para que las pruebas no ensucien los números. Límite a tener en cuenta: es probable que algunos bloqueadores de anuncios bloqueen el script, así que los números son un mínimo y no el total exacto de visitas.
